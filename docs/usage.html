pagesmark

Every flag, subcommand, and exit code. Same examples as the README.

Synopsis

pagesmark <command> [dir]
Tip: pagesmark --help prints this text in the terminal. pagesmark --version prints 1.0.0.

Flags and arguments

Flag / argumentMeaning
-h, --helpPrint detailed usage and exit 0.
-v, --versionPrint 1.0.0 and exit 0.
init [dir]Create docs/ under dir (default cwd) with index.html, styles.css, and logo.svg.

Exit codes

CodeMeaning
0docs/ written.
1Missing init subcommand.

Configuration

No configuration. Output paths are always <dir>/docs/{index.html,styles.css,logo.svg}. Existing files are overwritten.

Worked examples

Success path

pagesmark init ./mysite
{"dir":".../mysite/docs","files":["index.html","styles.css","logo.svg"]}

Failure path

Unknown command.

pagesmark
usage: pagesmark init [dir]

Exit code is 1.
