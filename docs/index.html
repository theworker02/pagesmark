pagesmark

Write docs/index.html, docs/styles.css, and docs/logo.svg so Pages on main /docs has somewhere to start.

1.00 / 1.0.0 branch main MIT Node.js >= 18

Overview

Empty Pages settings fail mysteriously. pagesmark drops a navy-and-gold stub that already matches this family's brand so you can enable Pages immediately.

Maintainers standing up documentation sites for small Node CLIs.

Install

Install globally from Git, or run with Node from a clone. There are no extra dependencies.

npm install -g git+https://github.com/theworker02/pagesmark.git
pagesmark --help
node src/cli.js --help

Usage

Synopsis: pagesmark <command> [dir]

See the full CLI reference for every flag, exit code, and example.

pagesmark 1.00 (1.0.0)

Usage:
  pagesmark init [dir]
  pagesmark --help
  pagesmark --version

Write a GitHub Pages stub:
  docs/index.html
  docs/styles.css
  docs/logo.svg

Enable Pages with: Settings → Pages → Deploy from a branch → main → /docs

Options:
  -h, --help       Show this help
  -v, --version    Print 1.0.0

Examples:
  pagesmark init
  pagesmark init ./website

Examples

Success

pagesmark init ./mysite
{"dir":".../mysite/docs","files":["index.html","styles.css","logo.svg"]}

Failure

Unknown command.

pagesmark
usage: pagesmark init [dir]

Exit code is 1.
